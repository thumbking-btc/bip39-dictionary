# BIP39 단어 학습 사전

BIP39의 2,048개 단어를 한국어로 공부할 수 있는 설치형 오프라인 영한사전입니다.

- 실행: https://thumbking-btc.github.io/bip39-dictionary/
- 현재 사전판: v2.2
- 핵심 기능: 실시간 검색, 알파벳 이동, 북마크, 뜻 가리기, 발음 듣기
- 설치 후 검색·북마크·뜻 가리기 등 핵심 기능을 오프라인에서 사용할 수 있습니다.
- 발음 듣기는 기기나 브라우저의 음성 서비스에 따라 인터넷 연결을 사용할 수 있습니다.

## 저장소 구조

- 저장소 루트의 HTML·서비스 워커·아이콘은 현재 공개 중인 검증된 배포본입니다.
- `source/`에는 Full HTML 원본, PWA 제작 소스, 이미지 원본과 검증 도구가 들어 있습니다.
- `.github/workflows/deploy-pages.yml`은 같은 소스로 PWA를 다시 만들고 검증한 뒤 GitHub Pages에 배포합니다.

자세한 제작 방법은 [`source/README.md`](source/README.md)에 정리되어 있습니다.

## 안전 안내

이 사전은 개별 단어를 공부하기 위한 도구입니다. 실제 복구문구를 입력하거나 붙여넣지 말고, 순서대로 검색하거나 북마크하지 마십시오.
